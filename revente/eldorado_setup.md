# Mise en place du compte vendeur Eldorado — checklist

> À faire **en premier** car le KYC peut prendre 24-48 h. Aucune vente n'est possible (pas de retrait) tant que le KYC n'est pas validé.

## 1. Création du compte vendeur
- [ ] Créer un compte sur https://www.eldorado.gg avec un **email dédié à l'activité** (pas ton perso principal)
- [ ] Activer le profil vendeur (Sell / Become a seller)

## 2. KYC (vérification d'identité)
- [ ] Lancer le KYC depuis les paramètres du compte
- [ ] Fournir une pièce d'identité valide
- [ ] ⚠️ Le **nom** doit être **exactement identique** à celui du compte bancaire de retrait, en alphabet latin

## 3. Méthode de payout
- [ ] Configurer le payout **SEPA** (RIB français)
- [ ] Vérifier que le **titulaire du compte = nom du KYC**
- [ ] Noter : SWIFT indisponible depuis 05/2026 → utiliser **SEPA** (ou Skrill/crypto en secours)

## 4. Repères à noter (pour le tableur)
- [ ] Délai de validation KYC constaté : __________
- [ ] Délai de payout après confirmation acheteur : __________
- [ ] Commission appliquée sur les comptes BS : __________ (attendu : 15 %)

## Rappels clés
- **Payout garanti dès confirmation acheteur** (point fort d'Eldorado) — mais après-vente courte (5 j) côté assurance acheteur.
- Tout se passe **dans la plateforme** : jamais de finalisation hors Eldorado (sinon perte de la protection).
- Provisionner un **buffer de remboursement** dès les premières ventes (couvre un éventuel ban Supercell post-vente, non couvert par l'escrow).
