# Grille de prix — comptes Brawl Stars (benchmark live 2026-05-31)

Source : annonces réelles Eldorado + PlayerAuctions. Prix en $ (≈ ×0,92 pour €).
⚠️ Toujours re-benchmarker les annonces live au moment de lister — le marché bouge.

| Palier | Compte **basique** (peu de max/skins) | Compte **chargé** (max + hypercharges + skins rares) |

| ~25 000 tr | 13-26 $ | 40-70 $ |

## Leviers de prix (par ordre d'impact — c'est ce qui fait ×10 à trophées égaux)

1. **Skins rares / inobtenables** (Star Shelly 2018, pins event, skins Brawl Pass anciens) → peuvent **doubler/tripler** le prix
2. **Hypercharges** → ~+5-8 $ chacune
3. **Brawlers Power 11 (max)** → +10-30 $ selon le nombre
4. **Trophées bruts** → impact le plus faible isolément (signal de "gros compte")

## Repère brutal
- Compte ~20k tr **sans composition** = 7-13 $ (à peine rentable après commission)
- Même palier **chargé** = 50-80 $
- → la valeur est dans la **composition**, pas le compteur de trophées
